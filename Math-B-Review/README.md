# 學測數學 B｜111～115 五年完整詳解

## 開啟方式

直接雙擊 `index.html` 即可；也可以用任何簡單的 local server 開啟。

## 使用流程

先選年度，快速掃描年度特色、必看考點、20 題地圖與最後 10 分鐘；題型地圖和推薦題可以跳到下方詳解。20 題詳解預設收合，寫完官方 PDF 模擬考後再逐題展開檢討。

## 檔案

- `index.html`：網站入口
- `style.css`：講義式版面與手機版樣式
- `script.js`：頁籤、題目卡片與 PDF 入口
- `data.js`：111～115 年題型、答案、快速複習與詳解資料

網站內另有依 `學測數學B_111-115_高分班課綱.md` 整理的「20 堂核心課」速讀區，每堂分成「要背」與「要理解」。

## 內容來源

官方 PDF 位於上層資料夾的 `數學B/`。若日後移動 PDF，請同步修改 `data.js` 內的 `FILES` 檔名或相對路徑。

## 注意

非選題的正式評分重點以各年度官方「非選擇題參考答案與評分原則」為準；網站的正式答題紙建議是考場速讀版，不能取代官方原件。
